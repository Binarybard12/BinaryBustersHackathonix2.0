# Smart Internship Portal

A web platform that connects students with internship opportunities using AI-powered skill extraction, ATS‑style resume scoring, and matching algorithms.

## Tech Stack
- **Frontend**: HTML, TailwindCSS, EJS, GSAP
- **Backend**: FastAPI (Python)
- **Database**: MongoDB
- **NLP**: spaCy, NLTK, TF‑IDF
- **File Processing**: pdfminer.six, docx2txt

## Quick Start
```bash
# Clone repo
git clone <repo-url>
cd smart-internship-portal

# Install dependencies
pip install -r requirements.txt

# Run development server
uvicorn backend.app:app --reload
```
